# Product Overview

This is a personal portfolio website for Bijay Jena, a Full Stack & AI Developer and Associate Team Lead at Squbix Digital.

## Purpose

Showcase professional experience, projects, skills, and achievements in an interactive, visually engaging format. The portfolio serves as both a resume and a demonstration of technical capabilities.

## Key Features

- Interactive hero section with 3D tech stack visualization
- Comprehensive sections: About, Experience, Case Studies, Skills, Projects, Education, Contact
- AI-powered chatbot using Google Gemini AI (Firebase Cloud Functions)
- Dark/light theme support
- Smooth animations and micro-interactions
- Mobile-first responsive design
- Performance-optimized with lazy loading and code splitting

## Target Audience

- Potential employers and recruiters
- Clients seeking development services
- Professional network and collaborators
- Anyone interested in the developer's work and capabilities

## Core Value Proposition

A modern, performant portfolio that demonstrates technical expertise through both content and implementation quality, featuring 60fps animations, accessibility compliance, and enterprise-grade architecture.
